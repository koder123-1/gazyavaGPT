DejaVuSans.ttf — шрифт DejaVu (DejaVu Fonts, лицензия Bitstream Vera / Public Domain).
Источник: https://github.com/matplotlib/matplotlib (lib/matplotlib/mpl-data/fonts/ttf/DejaVuSans.ttf)
Официальный сайт: https://dejavu-fonts.github.io/

Нужен, чтобы PDF с кириллицей собирался и на Render, где может не быть системных шрифтов.
Свой шрифт можно указать через PDF_FONT_PATH.
